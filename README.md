# Cristiane Souza - Personal Website

A clean, creative portfolio website showcasing work across industry and academia.

## Color Palette
- **Sage**: #8B9D83
- **Teal**: #4A7C7E
- **Gray**: #2C3333 / #6B7280 / #F3F4F6
- **Gold**: #C9A961

## Structure
- `index.html` - Landing page
- `about.html` - About section
- `industry.html` - Industry work
- `academia.html` - Academic work
- `stories.html` - Short Stories (white papers)
- `contact.html` - Finding Cris (social links)

## Setup
1. Clone this repository
2. Update content in each HTML file (currently using placeholders)
3. Update links in `contact.html` with your actual profiles
4. Push to GitHub Pages

## Deployment
Site is deployed via GitHub Pages at: https://souza-cris.github.io
