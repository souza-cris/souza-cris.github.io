💼 Product Manager  ·  💻 Software Engineers  ·  🔎 QA / Testers  ·  📈 Business Analyst  ·  🎨 UX Designer  ·  🛠️ DevOps Engineer  ·  🚀 Astronaut (Subject-Matter Expert)

Module Overview

  • Planning: AI auto-generates user stories & effort estimates
  • Coding: GitHub Copilot as AI pair programmer in VS Code
  • Testing: AI auto-generates test cases, detects bugs early

👥 Module 2: Agile Roles

  • Product Manager: AI handles refinement → PM focuses on strategy

Key Reference — SDLC Compression

Traditional SDLC

  1. PM writes PRD manually
  2. Architects design system
  3. Devs code feature
  4. QA writes & runs tests
  5. Ops deploys to production

AI-Augmented SDLC

  1. AI drafts PRD from notes
  2. AI generates architecture options
  3. AI + dev pair-program feature
  4. AI auto-generates tests
  5. AI-assisted CI/CD deployment

Objective: Identify how AI integrates into each phase of the Software Development Life Cycle.
Q1 · MODULE 1 — SDLC
The Starman team is in the Planning phase of the NASA mission app. The Product Manager needs to write user stories and estimate effort for 40+ features. Which AI application would be MOST valuable in this SDLC phase?
  • A) Use AI to deploy the application directly to production
  • B) Use AI to write the final test scripts before any code is written
  • C) Auto-generate user stories and estimate effort using AI models trained on historical project data
  • D) Have AI replace the Product Manager and run planning autonomously
Q2 · MODULE 1 — SDLC
During the Coding phase, Starman engineers use GitHub Copilot to build the spacecraft tracking module. According to the lecture, how do the engineers use GitHub Copilot?
  • A) They upload entire projects and let Copilot rewrite them from scratch
  • B) Copilot acts as an AI pair programmer integrated into VS Code, suggesting code line-by-line and in blocks
  • C) Engineers use it only to write documentation and comments, not actual code
  • D) Copilot replaces the need for code reviews by automatically approving all changes
Q3 · MODULE 1 — SDLC
The Starman QA team needs to test the mission control dashboard before deployment. How does AI MOST significantly change the Testing phase of the SDLC?
  • A) AI auto-generates test cases and detects bugs before deployment, covering more edge cases
  • B) AI eliminates the need for a QA team entirely
  • C) AI only tests the user interface but cannot test backend logic
  • D) AI delays testing until after deployment to collect real user data
Q4 · MODULE 1 — SDLC
After coding and testing the mission control dashboard, the Starman team needs to deploy it to production. According to the lecture, how does AI change the Deployment phase of the SDLC?
  • A) AI skips deployment and ships code directly to users without any review
  • B) AI requires manual approval for every single line of code before deployment
  • C) AI has no role in deployment — it only helps with coding and testing
  • D) AI monitors releases and can auto-rollback when it detects anomalies
